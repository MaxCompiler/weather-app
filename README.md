# Weather App - Aplicación de Clima

Una aplicación web moderna para consultar el clima de cualquier ciudad del mundo en tiempo real, con autocompletado de ciudades y historial de búsquedas.


## Características

**Búsqueda de ciudades** - Ingresa el nombre de cualquier ciudad
**Autocompletado inteligente** - Sugerencias mientras escribes
**Información detallada del clima**:
   - Temperatura actual
   - Sensación térmica
   - Humedad
   - Presión atmosférica
   - Velocidad del viento

**Iconos dinámicos** - Cambian según el clima actual
**Historial de búsquedas** - Guarda tus últimas 5 ciudades
**Diseño responsive** - Funciona en móvil, tablet y desktop
**Tema oscuro** - Interfaz moderna y cómoda para los ojos
**LocalStorage** - Guarda el historial en tu navegador

---

## Tecnologías Utilizadas

- **HTML5** - Estructura semántica
- **CSS3** - Diseño y animaciones (gradientes, transiciones, flexbox)
- **JavaScript ES6+** - Lógica de la aplicación
- **OpenWeatherMap API** - Datos del clima en tiempo real
- **Font Awesome** - Iconos profesionales
- **LocalStorage** - Almacenamiento local del navegador

- Navegador web moderno (Chrome, Firefox, Safari, Edge)
