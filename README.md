# Weather App - Aplicación de Clima

Una aplicación web moderna para consultar el clima de cualquier ciudad del mundo en tiempo real, con autocompletado de ciudades e historial de búsquedas.

---

## Características

- **Búsqueda de ciudades:** Ingresa el nombre de cualquier ciudad del mundo.
- **Autocompletado inteligente:** Sugerencias automáticas mientras escribes.
- **Información detallada:**
  - Temperatura actual y sensación térmica
  - Porcentaje de humedad
  - Presión atmosférica
  - Velocidad del viento
- **Iconos dinámicos:** Representación visual según el estado del clima.
- **Historial de búsquedas:** Almacena las últimas 5 consultas.
- **Diseño responsive:** Adaptado para móviles, tablets y escritorio.
- **Tema oscuro:** Interfaz moderna y optimizada para la vista.
- **Persistencia local:** Uso de LocalStorage para guardar preferencias e historial.

---

## Tecnologías Utilizadas

- **HTML5** - Estructura semántica
- **CSS3** - Diseño moderno, Flexbox, gradientes y animaciones
- **JavaScript ES6+** - Lógica asíncrona y manipulación del DOM
- **OpenWeatherMap API** - Proveedor de datos meteorológicos
- **Font Awesome** - Iconografía

## Instalación

### Requisitos

- Navegador web moderno (Chrome, Firefox, Safari, Edge)
- Conexión a internet

### Pasos

1. Descarga o clona el proyecto:
```bash
   git clone https://github.com/tuusuario/weather-app.git
   cd weather-app
```

2. Abre el archivo `index.html` en tu navegador
   - O usa Live Server en VS Code (click derecho → "Open with Live Server")

3. ¡Listo para usar!

---

## Cómo Usar

1. Ingresa el nombre de una ciudad en el cuadro de búsqueda
2. Verás sugerencias automáticas mientras escribes
3. Haz clic en una sugerencia o presiona Enter
4. Se mostrará la información completa del clima
5. El historial se actualiza automáticamente
